# Plugin Mxc

Exécution d’outils en bac à sable au niveau du système d’exploitation via MXC pour les hôtes Windows compatibles avec MXC : exécute les commandes dans ProcessContainer (Windows) avec les fichiers de stratégie MXC configurés.

## Distribution

  * Paquet : `@openclaw/mxc-sandbox`
  * Mode d’installation : npm ; ClawHub

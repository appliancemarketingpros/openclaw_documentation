# Mxc Plugin

MXC를 지원하는 Windows 호스트에서 MXC를 통한 OS 수준의 샌드박스 도구 실행: 구성된 MXC 정책 파일을 사용하여 ProcessContainer(Windows)에서 명령을 실행합니다.

## 배포

  * 패키지: `@openclaw/mxc-sandbox`
  * 설치 경로: npm; ClawHub

# Crabbox Plugin

Crabbox CLI द्वारा समर्थित क्लाउड वर्कर प्रदाता।

## वितरण

  * पैकेज: `@openclaw/crabbox-provider`
  * इंस्टॉल मार्ग: OpenClaw में शामिल


## सतह

अनुबंध: `workerProviders`

## कॉन्फ़िगर करें

प्रोफ़ाइल स्कीमा और जीवनचक्र संबंधी टिप्पणियों के लिए [क्लाउड वर्कर परिवेश](</hi/gateway/configuration-reference#crabbox-profile>) देखें।

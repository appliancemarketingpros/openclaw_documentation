# Mxc Plugin

MXC を介した OS レベルのサンドボックス化されたツール実行：設定済みの MXC ポリシーファイルを使用して、Windows ProcessContainer 内でコマンドを実行します。

## 配布

  * パッケージ：`@openclaw/mxc-sandbox`
  * インストール経路：npm、ClawHub

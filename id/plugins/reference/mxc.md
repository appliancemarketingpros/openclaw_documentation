# Plugin Mxc

Eksekusi alat yang disandbox pada tingkat OS melalui MXC: menjalankan perintah dalam Windows ProcessContainer dengan file kebijakan MXC yang telah dikonfigurasi.

## Distribusi

  * Paket: `@openclaw/mxc-sandbox`
  * Rute instalasi: npm; ClawHub

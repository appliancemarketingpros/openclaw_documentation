# Плагин Mxc

Изолированное выполнение инструментов на уровне ОС через MXC для хостов Windows с поддержкой MXC: команды выполняются в ProcessContainer (Windows) с настроенными файлами политик MXC.

## Распространение

  * Пакет: `@openclaw/mxc-sandbox`
  * Способ установки: npm; ClawHub

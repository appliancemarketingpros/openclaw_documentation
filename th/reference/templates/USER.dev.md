# USER.md - โปรไฟล์ผู้ใช้

  * **ชื่อ:** เหล่า Clawdributors
  * **คำเรียกที่ต้องการ:** พวกเขา (แบบกลุ่ม)
  * **สรรพนาม:** พวกเขา
  * **เขตเวลา:** กระจายอยู่ทั่วโลก (หากไม่มีข้อมูลจะใช้เขตเวลาของโฮสต์ ดู[เขตเวลา](</th/concepts/timezone>))
  * **หมายเหตุ:**
    * เรามีหลายคน เป็นผู้มีส่วนร่วมใน OpenClaw ซึ่งเป็นที่ที่ระบบทดสอบ C-3PO ทำงานอยู่
    * C-3PO มีไว้เพื่อช่วยแก้ไขข้อบกพร่องและให้ความช่วยเหลือทุกเมื่อที่ทำได้
    * เราทำงานร่วมกันข้ามเขตเวลาเพื่อพัฒนา OpenClaw ให้ดียิ่งขึ้น
    * เหล่าผู้สร้าง เหล่านักพัฒนา และผู้ที่เจาะลึกเข้าไปในโค้ด

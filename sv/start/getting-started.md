**Tip**

Kontrollera din Node-version med `node --version`. **Windows-användare:** Windows Hub-appen som körs direkt i Windows är det enklaste skrivbordsalternativet. Installationsprogrammet för PowerShell och Gateway via WSL2 stöds också. Se [Windows](</platforms/windows>). Behöver du installera Node? Se [Konfiguration av Node](</install/node>).

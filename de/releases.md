# Versionshinweise

Diese Seiten sind die leserorientierte Version der OpenClaw-Releases. Sie halten die zentrale Geschichte, die praktischen Auswirkungen, Quelllinks und den Dank an Beitragende zusammen, ohne dass Sie zuerst das rohe Changelog durchsuchen müssen.

## Releases

  * [v2026.6.11](</de/releases/2026.6.11>) \- Zuverlässigkeitskorrekturen für Antworten, Senden, Wiederverbindungen, Modelleinrichtung, Sessions und sicherere Admin-Standardwerte.


## Rohe Release-Historie

Verwenden Sie die kuratierten Hinweise, wenn Sie die Produktgeschichte möchten. Verwenden Sie die rohe Historie, wenn Sie eine kompakte Maintainer-Abrechnung benötigen:

  * [GitHub-Releases](<https://github.com/openclaw/openclaw/releases>)
  * [CHANGELOG.md](<https://github.com/openclaw/openclaw/blob/main/CHANGELOG.md>)

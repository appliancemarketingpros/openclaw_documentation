# Plugin Mxc

Esecuzione di strumenti in sandbox a livello di sistema operativo tramite MXC per host Windows compatibili con MXC: esegue i comandi in ProcessContainer (Windows) con i file dei criteri MXC configurati.

## Distribuzione

  * Pacchetto: `@openclaw/mxc-sandbox`
  * Metodo di installazione: npm; ClawHub

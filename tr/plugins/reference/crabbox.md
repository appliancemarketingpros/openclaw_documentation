# Crabbox plugin'i

Crabbox CLI tarafından desteklenen bulut çalışanı sağlayıcısı.

## Dağıtım

  * Paket: `@openclaw/crabbox-provider`
  * Kurulum yolu: OpenClaw'a dahildir


## Yüzey

sözleşmeler: `workerProviders`

## Yapılandırma

Profil şeması ve yaşam döngüsü notları için [Bulut çalışanı ortamları](</tr/gateway/configuration-reference#crabbox-profile>) bölümüne bakın.

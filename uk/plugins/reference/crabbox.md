# Plugin Crabbox

Постачальник хмарних робочих середовищ на базі CLI Crabbox.

## Розповсюдження

  * Пакунок: `@openclaw/crabbox-provider`
  * Спосіб установлення: входить до складу OpenClaw


## Поверхня

контракти: `workerProviders`

## Налаштування

Схему профілю та примітки щодо життєвого циклу див. у розділі [Середовища хмарних робочих процесів](</uk/gateway/configuration-reference#crabbox-profile>).

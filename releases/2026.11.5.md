Run managed Gateway and node services from a [standalone OpenClaw build](<https://docs.openclaw.ai/install/standalone>) without a separate Node or Bun executable. Choose the standalone runtime and point it at the executable. Reinstalling or repairing the Gateway service retains that choice. Keep the whole build directory together, and rebuild older artifacts that lack the service runtime check.⁠

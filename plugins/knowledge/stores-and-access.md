**Warning**

There is no complete backup/restore procedure. Back up `registry.sqlite`, each store's `state.sqlite`, and its `vault/` directory together. The database holds receipts, history, withdrawal safeguards, and session activity that cannot be rebuilt from Markdown or Git.

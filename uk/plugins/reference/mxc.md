# Плагін Mxc

Ізольоване виконання інструментів на рівні ОС через MXC для сумісних із MXC хостів Windows: команди виконуються в ProcessContainer (Windows) із налаштованими файлами політик MXC.

## Розповсюдження

  * Пакунок: `@openclaw/mxc-sandbox`
  * Спосіб встановлення: npm; ClawHub

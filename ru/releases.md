# Примечания к релизам

Эти страницы будут версией релизов OpenClaw для читателей. Они объединяют главное, практическое влияние, ссылки на исходники и благодарности участникам, чтобы не приходилось сначала просматривать сырой журнал изменений.

## Релизы

  * [v2026.6.11](</ru/releases/2026.6.11>) \- Исправления надежности для ответов, отправки, переподключений, настройки моделей, сессий и более безопасных значений по умолчанию для администрирования.


## Сырая история релизов

Используйте подготовленные примечания, когда нужна история продукта. Используйте сырую историю, когда нужен компактный учет для сопровождающих:

  * [Релизы GitHub](<https://github.com/openclaw/openclaw/releases>)
  * [CHANGELOG.md](<https://github.com/openclaw/openclaw/blob/main/CHANGELOG.md>)

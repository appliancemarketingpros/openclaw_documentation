# Plugin Crabbox

ผู้ให้บริการ Cloud worker ที่ทำงานผ่าน CLI ของ Crabbox

## การเผยแพร่

  * แพ็กเกจ: `@openclaw/crabbox-provider`
  * เส้นทางการติดตั้ง: รวมอยู่ใน OpenClaw


## พื้นผิว

สัญญา: `workerProviders`

## การกำหนดค่า

ดูสคีมาของโปรไฟล์และหมายเหตุเกี่ยวกับวงจรชีวิตได้ที่ [สภาพแวดล้อม Cloud worker](</th/gateway/configuration-reference#crabbox-profile>)

# Plugin Mxc

Execução de ferramentas em sandbox no nível do sistema operacional via MXC para hosts Windows compatíveis com MXC: executa comandos no ProcessContainer (Windows) com arquivos de política MXC configurados.

## Distribuição

  * Pacote: `@openclaw/mxc-sandbox`
  * Rota de instalação: npm; ClawHub

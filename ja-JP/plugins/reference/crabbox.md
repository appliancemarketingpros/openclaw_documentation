# Crabbox plugin

Crabbox CLI を基盤とするクラウドワーカープロバイダー。

## 配布

  * パッケージ: `@openclaw/crabbox-provider`
  * インストール方法: OpenClaw に同梱


## サーフェス

コントラクト: `workerProviders`

## 設定

プロファイルスキーマとライフサイクルに関する注意事項については、[クラウドワーカー環境](</ja-JP/gateway/configuration-reference#crabbox-profile>)を参照してください。
